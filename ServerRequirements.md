## Users
- Admin
- Teacher
- Player

### Teacher
The teacher account can access a set of Players that is given to it by the admin. 

### Player
The player can only access the data of other players via the game itself and will be limited to following 

`string PlayerName`
`int Level;`
`int Points;`
`int TotalPoints;`
`int Coins;`
`List<ActivityData> Progress;` 
`List<ItemData> Inventory;`
`List<string> CharacterStyle;`
`List<string> SelectedPersonas1;`
